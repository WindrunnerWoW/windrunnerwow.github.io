Well met!

## Version Update.

Today is the time for release 1.19.0. You can find all the release notes [here](/changelog/1-19-0).

If you use the Launcher, it should ask you to update and do all the Hearthstone setup work. If you don't, bye, cause this is complicated.

## HEARTHSTONE! AND MORE (a little bit more)!

Have fun playing Hearthstone. I mean, what else is there to say? You probably already saw the feature spotlight. If not, [check it out](/news/FS_Hearthstone).

On top of that, I added a few optional quality-of-life improvements to the user interface. They're all toggled on by default, but you can turn them off in the interface settings. 

Additionally, the launcher has been updated a little. You can now toggle on PTR mode, which I'll use to test updates before a big update comes out. The launcher also downloads the Hearthstone art for you... which you of course need to see the cards... straight from HearthstoneJSON.com. There are also a few more quality-of-life improvements and fixes in the launcher, in game, and in my modules, plus some upstream merges.

## What's next

I added a new point to the roadmap: improving the bot implementation. The more I played and the harder the dungeons got, the more annoyed I was with the current bots. So this will be 1.19.1. Probably not much more than that. 

Apart from that, I updated the roadmap for my 3 planned 1.19.x releases. I expect 1.19.1 to go live in ~ 2-3 months, since this will be a lot of work.

Stay tuned and take care.
