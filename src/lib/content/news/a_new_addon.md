## Windrunner Voiceover

Just a short info. A few days ago I uploaded my fork from [MrThingers Voiceover](https://github.com/mrthinger/wow-voiceover).

It looks a little different and also includes support for Windrunner (and all turtle wow servers). You can find the data [here](https://github.com/WindrunnerWoW/windrunner-voiceover-data).

Just make sure to use [Windrunner-Voiceover](https://github.com/WindrunnerWoW/windrunner-voiceover) since the data only works with that.

Why? Well, because the base version doesnt support a quest you could get from multiple questgivers. E.g. Mage quests can be received from multiple questgivers, but its always the same quest. That resulted in wrong voices, since only one voiceline existed for a single quest.

Solved that, changed the look a little, generated the voice data for all turtle wow quests...
